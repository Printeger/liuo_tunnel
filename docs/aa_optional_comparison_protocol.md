# TA 基础、AA 可选：默认关闭与本轮验证

2026-10-23 用户授权：TA 为基础能力，AA 为可选增强能力，在配置中提供开关，默认关闭；用上一轮相同输入比较，不重跑其他方法。

## 实现与假设

复用 `uwb.use_aa`，将缺省值从 true 改为 false，所有项目主配置显式 false；true 为主动开启。该开关只控制**新 AA 观测进入估计器**，TA、LiDAR、IMU、测量噪声和求解参数不变。原始 AA 消息继续发布/记录，以保持冻结输入完全相同；不将关闭 AA 视为传感器故障。验证后的 AA 在进入待标定缓存、扩图缓存、摘要或图之前被记录为 `AA_ABLATION_DISABLED`。

每帧检查 AA 关闭时新增 AA、累计 AA 和摘要均为零。导出地图记录 `uwb_information.use_aa` 和已接受 AA 数。历史地图没有该字段时，不推断为 TA-only；关闭当前 AA 不会自动移除历史地图先验中已吸收的 AA。

假设：关闭 AA 后 TA 紧耦合仍可运行；初始化、精度和地图质量是否改善由本轮数据判断，不预设 AA 必须有益或有害。成功/否定条件：新运行日志证实 AA 进入图的计数为零、TA 确实使用，且有实际轨迹/状态或明确失败原因；若无输出或失效，保留失败，不调参重试。
