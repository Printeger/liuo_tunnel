# 几何关联与有限候选初始化：本轮实验

## 输入核查与预声明（实验前）

固定复用 seed 0 冻结输入 `20261021T193009Z_074`。只读取原始 PointCloud2、IMU、UwbRange、已知外参及 recorded surveyed map；不读 scenario、真值、模拟器源码或边界。先取 stamp 3.0 和 50.0 的两个 snapshot：前者启动段，后者为不同位置的已有观测，不冒充一次新的静止启动。该检查不代表任意起点覆盖。

现有 KnownMap 只有 ID、三维均值、联合地图协方差及外参/来源；没有逐站 signed lateral offset、其局部参考截面、地图中线关联或地面/顶板。合同描述“可提供”，不能据此从 ID 或布局循环生成数值。已知地图中的 z 合法用于第二阶段原始测距；不等于已知地面高度，也不代表首轮标定已完成。

按优先级检验三个可证伪假设：

1. 原始点云不足以提供局部截面。固定抽样、固定 RANSAC 预算提取四个支撑面，记录点数、残差、法向及局部范围；若能获得两组近似正交面，则否定“完全缺局部几何”。不以拟合残差冒充绝对地图精度。
2. 当前地图/安装信息足以把局部内部区域直接放到地图。检查实际关联字段；并推导即使理想地给定水平有符号偏距，其方程对竖直平移是否仍不敏感。用实测点云和面作共同刚体变换，有限 yaw={0,π/2,π}、高度平移={0,7 m} 验证局部几何残差不变。这些是坐标重表达测试，不是虚构额外实测/地图先验，不验证全系统 UWB 不变性。
3. 近处墙上基站能消除上述缺口。检查同时间真实消息的 TA 距离与局部点云支撑范围；只有能在实际观测范围内关联到对应墙段/地面时才可用安装约束。远处锚点不自动属于当前拟合截面的无限延伸；若需直线等截面/地面坡度连续假设，必须作为缺少的关联条件单列。

成功路径：合法关联足够则实现有限候选生成与筛选，不重复加入派生强先验。停止路径：推导/针对性实验明确一个必要的局部几何—地图关联仍缺失，并写出最小补充条件及适用范围；不据此声称所有 UWB/运动初始化算法不可行。不开全程/多种子，不调整噪声或无限扩 RANSAC/候选预算。
