# 隧道部署与初始化条件

确认日期：2026-10-22（北京时间）。来源：用户明确提供的现场条件。
本合同覆盖 handbook 中较早的入口启动、固定高度及基站安装先验假设；记录需求，不代表实现或验收已经完成。

## 1. 可用信息与不可默认的信息

| 项目 | 已确认条件 | 估计器中的含义 |
|---|---|---|
| 机器人活动区域 | 位于左右墙之间、地面以上、顶板以下 | 可使用真实隧道内部的粗可行区域；不能用模拟器的精确边界代替实际观测或资料 |
| 启动位置 | 可以在隧道内任意区域、任意可行空间位置启动 | 没有固定发车点、入口位置或已知里程；“任意空间”不包括墙外、地下或顶板外 |
| 平台 | 可能为地面机器人，也可能为无人机 | 完整 6DoF；没有固定离地高度、轨道中心线或轮式非完整运动约束 |
| 传感器外参 | LiDAR、IMU、UWB 天线之间的外参已知 | 使用已标定固定外参，记录来源；未提供数值误差范围，不虚构精度 |
| 基站安装 | 在隧道墙壁上，左右随机交替 | 可提供每个基站到局部隧道中线的有符号横向距离，符号标识墙侧；不假定严格奇偶交替 |
| 基站高度 | 未知 | 高度需要优化，不锁定为安装图或仿真中的高度 |
| 粗安装高度 | 可提供大致的相对安装信息 | 仅作初值；相对地面的高度不自动等于地图绝对 z，也不自动成为带权测量先验 |
| 基站前后顺序 | 首轮无地图时未知 | 不从 ID、数组顺序或安装循环推断；首轮轨迹与联合标定结果可形成带不确定度的顺序信息 |
| 上电操作 | 能保证静止一段时间 | 可进行静止 IMU 初始化；具体时长及实际噪声/偏置误差需登记，不保证无误差姿态 |
| 精确入口位置、绝对航向 | 不提供 | 不添加外部位置或测绘航向先验；隧道方向是几何参考，不是给定的精确航向角 |
| LiDAR | Mid-360，可用点云估计相对地面高度、墙面方向、局部通道几何 | 原始点云、IMU 和 UWB 均可参与初始化和紧耦合，不将其输出虚构为独立外部真值 |

“到中线的距离”在本合同中指用户用于区分左右墙的**有符号横向偏距**，不是由高度和横向共同形成的无符号三维径向距离。记录其参考中线/截面、正方向、单位、来源及实际误差；已知横向偏距不等于已知纵向坐标或高度。弯道采用局部参考，不能默认一条精确已知的全程中心线。

左右的正负必须绑定一个声明的隧道方向约定，不能随机器人掉头翻转。首次运行可选局部坐标规范，但需一致转换墙侧资料；资料方向与局部轴的关联未知时保留关联假设，不能借符号偷偷提供全局航向。

## 2. 隧道空间边界与 LiDAR 使用

用户授权使用“位于隧道内”的物理约束，不授权固定机器人高度、沿真值轨道运动或精确已知起点。粗可行区域可用于候选筛选或具有明确不确定度的几何约束。需记录墙、地面、顶板由实际点云、复用地图还是独立工程资料获得，以及如何表达在当前地图坐标系中。

只知道宽高，不足以知道隧道在基站地图中的精确位置。必须处理局部几何到地图的关联与误差，不能直接读取模拟世界的 `y∈[-3,3]、z∈[0,5]`。早期错误候选落在模拟隧道外，只提示有价值的物理判别条件；必须用估计器实际可获得的信息验证其排除效果。

允许从点云估计地面高度、墙面方向和通道轴线，并与原始测距、IMU 联合使用。同一批点云或 IMU 推导的结果不能再作为独立高置信先验重复计数；新增几何因子、候选筛选或初始化信息移交应说明数据复用及相关性。“所有传感器均可使用”不包括仿真真值。

## 3. 朝向与 Mid-360 的能力边界

用户提出车头朝洞内的操作意图，并询问全向点云是否允许任意朝向初始化。当前**不将固定朝向作为算法前提**，不提供数值 yaw 或精确测绘航向；若某次作业确实保证朝洞内，只能显式登记为粗方向信息，不能推广为所有运行的保证。

Mid-360 的水平视场为 360°，垂直视场为 59°，不是完整球面覆盖；参见 [Livox 官方规格](https://www.livoxtech.com/mid-360)。工程上需区分：

- **局部隧道轴线**：几何可见且足够时，可从墙面和通道形状估计；机身水平朝向不必与轴线重合。任意姿态、遮挡和几何退化下不保证都能估计。
- **轴线的正反方向**：重复或对称的直隧道可能存在 180° 歧义；看见轴线不等于知道哪边是洞口。
- **洞口位置与全局航向**：洞口可能超出量程、被弯道或遮挡隔开。360° 视场不保证在任意启动位置看见洞口或取得绝对航向。

任意启动位置/不同初始朝向需要验证；方向有歧义时保留候选或报告未完成初始化，不默认为“车头方向就是地图正轴”。现有 snapshot 合成扫描结果不代表已经验证真实 Mid-360 扫描时序、覆盖及去畸变。

## 4. 首次自标定与地图复用

**首次无地图运行：** 起点定义为局部原点，仅选择坐标规范；重力给出竖直参考，yaw 规范不冒充绝对航向观测。输入为实际原始传感器、已知外参、墙侧/有符号横向安装信息、仅作初值的粗高度信息及可获得的局部几何。基站纵向坐标、高度、前后顺序未知，需联合估计。初始猜测不作为独立观测入图。不能强制从入口特征段启动，也不能由 ID 得到里程。未可观或存在多解时保留不确定性和无效状态，不保证完成一次运行就必然得到可复用地图。

**地图复用：** 读取首轮有效地图及其联合不确定度，从当前接收的 UWB 原始测距结合 LiDAR/IMU 和可用局部几何，估计机器人在该地图中的位置与朝向。允许任意隧道内起点，不重新固定起点为地图原点；不能只根据首次运行顺序认定当前处于某个区段。历史顺序是地图推断结果，不是新独立测量。存在分支时必须判别或报告歧义，不能以低残差/小局部协方差替代全局初始化成功。

第二阶段已知地图仍用于隔离紧耦合定位问题；surveyed/oracle 实验输入不是“首轮已经知道基站高度”的部署条件。此合同不把未知基站自标定和地图复用提前列为第二阶段已实现功能。

## 5. 误差、验证与当前实施边界

用户没有提供横向安装距离、粗高度、墙面/地面几何、外参的数值精度；不要自动填写 σ=0.30 m 等默认精度作为现场承诺。每项输入区分：实际观测及误差、允许范围、优化初值、坐标规范。工程实验可显式登记假设误差并做敏感性分析，但不得标为已确认现场数据。没有额外入口位置、高度或航向测量这一点已经回答，不再以重复询问同一问题作为唯一推进条件。

保留任意连续 1 km 最多 3 基站、当前 7 站/400 m 候选、800 m 真实三维量程、LOS、σ=0.10 m UWB 噪声；第二阶段退出条件以 handbook 第 7 节本次用户授权修订为准。仿真的周期墙侧/已知高度、轨道运动、入口设备段仅为测试世界设置，不能转为生产估计器先验。

后续实现和所属阶段验收需覆盖：入口以外的启动、不同初始朝向、无人机式不同离地高度、未知基站高度/顺序、可行区域的坐标关联与误差，以及几何不足时的诚实失败。对相同原始输入比较可行区域/安装信息启用和关闭，单独报告初始化分支与恢复情况；不跳过启动段、不把参考精度失败改写为达标。保留当前阶段边界，先做代表性验证，再考虑扩大 campaign。

本次仅确认并记录需求。已有静止、零速度、重力方向、IMU 偏置和已知地图先验的代码参数，尚需核对与现场条件的一致性；现有精度失败、断流漂移、状态及后验可信度问题不因文档更新而消失。

## 6. 第二阶段范围修订（2026-10-22，用户明确授权）

本轮仅验证少量预声明起点/朝向（一个固定种子）的初始化、冻结输入正常全程 ON/OFF 和 5 s/20 s 断流。不要求穷举任意启动、完整无人机工况、未知基站自标定、10 种子或全面部署认证。已知地图实验保留外部地图及其联合不确定度；不将实验地图当成首轮现场已知高度的承诺。

几何筛选必须明确实际传感器/安装资料来源、地图关联与误差，不能从模拟器读取边界。工程假设需显式标注；同批点云派生几何不能重复加入独立强先验。未排除分支则初始化未完成。旧精度目标及严格统计达标后移，不免除实际有效性、正确协方差输出和诚实状态要求。
