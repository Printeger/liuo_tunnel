# 静态 AA 物理身份与计权合同

状态：实施中。当前仅完成 estimator-thread 事务账本的第一层测试；生产接入、检查点与 C05–C09 验收尚未完成。依据 `curved_tunnel_static_aa_requirements.md`，不改变共享 `liuo_uwb_msgs`。

## 生命周期与身份

`network + deployment_epoch` 标识固定物理部署。驱动 session、ROS 时钟重置和交付 frame 不创建新的物理测距。移动或更换 Anchor 必须更换部署并明确重建联合后验，不能复用旧 prior 后只清空去重集合。

`StaticRangeBlock` 第一层实现是一条独立物理测距的叶记录（count=1），不是均值报文。`physical_id` 在一个部署内全局唯一；端点规范化为无向对，冲突端点、数值或方差均拒绝。同一个 ID 的反向报告、重复交付不能创建新信息。不同 ID 的独立性仍须由输入来源合同证明，不能由 ID 本身推出。

当前支持的误差模型是 `independent-gaussian-v1`：同一固定三维端点距离、独立零均值高斯误差、已知正方差。单位分别为 m 与 m²。生产入口还必须核验模型来源/独立性证据，不能因为报文自报模型字符串就信任它。非独立、未知来源、从坐标后验反推的距离不支持。

网络、部署和物理 ID 各限 1–256 字节，不含 NUL。账本容量由构造时指定；达到容量后拒绝新物理 ID，保留旧去重历史，绝不淘汰旧 ID 后允许重计权。重复 ID 在满容量时仍可判定。候选/队列另需独立容量，当前模块不承担端点初始化。

## 图更新事务

`prepare(records)` 返回候选账本及受影响边的完整未吸收摘要，不修改已提交状态。`updates()` 只包含新增物理信息的边；纯重传连因子替换都不触发。摘要复用既有 `GaussianRangeSummary` 和 `AnchorAnchorRangeFactor`，保留 scatter 常数项。

图的 owner 根据这些更新移除旧显式因子并加入新摘要，通过真实 solver 返回值绑定新 factor indices。只有 solver 成功后调用 `commit(transaction)`。失败必须丢弃该候选并恢复/重建求解器后重试；本模块不声称 GTSAM 异常具有回滚保证。跨账本或过期事务拒绝。回调线程不得操作本模块或求解器。

地图检查点必须将联合后验与精确已吸收物理叶集合原子保存，禁止只保存总数。`absorbed_checkpoint()` 生成待嵌入联合地图的 `liuo_absorbed_static_leaves_v1` 账本，不改变当前在线图，也不写文件。它包含所有已提交叶（含先前 prior 吸收的叶），没有 runtime factor indices。仅当同一地图后验确实吸收这些叶时才能持久化它。恢复构造器保留这些叶的去重身份，清空显式摘要；缺少精确账本的旧地图不能调用此路径假设已吸收集合为空。

加载后只允许未吸收的独立增量生成显式因子。携带旧叶与新叶的累计交付仅增加新叶；修改同一叶的内容拒绝。后续 wire record 必须携带精确叶覆盖与可验证内容；仅 revision 增长不能证明独立。当前尚未接通生产地图的原子写入、累计 wire record 或 prior 吸收移交，不可用于宣称地图复用已支持。

## 项目内消息

`liuo_tunnel_msgs/msg/StaticAnchorRecord` 是独立缓存记录，原始 `liuo_uwb_msgs/msg/UwbObservationBatch` 保持不变。每条记录最多 128 个叶：`covered_blocks` 与叶的 `physical_id` 集合必须精确相等且无重复。叶保留物理测量方、采集时间/valid/time_basis；record 保存网络、部署、来源身份、record ID、revision、无向端点、模型和有效性。Header 为软件发布时刻，frame_id 为空；接收时刻由接收端另外记录。分片可以有不同 record ID，但重复物理叶的身份必须一致。

`StaticRecordInput` 是无状态校验器，不持有已融合水位、不按 revision 自动累计、不访问车辆时间窗。当前仅支持明确共享仿真时钟且有效的采集时间，采集不能晚于发布；迟到没有 age 截止。配置必须绑定 source_identity、噪声与独立性依据、方差和时基；错误来源、覆盖集合或模型拒绝。消息的自报来源不构成物理证据，运行 owner 仍须将发布者绑定到审计过的已交付输入。

800 m 是生成端的真实三维测距可达条件；加噪距离不是无噪声真实距离，输入端不以 800 m 硬截断高斯观测。物理可达性和 reporter→车辆交付仍必须由生成/衍生数据证据审计，不能由这个校验器替代。

生产节点通过可选 `uwb.static_edges` 配置订阅该消息。回调只校验、记录 CDR 和入队（最多 2048 叶）；估计器线程转交 `StaticEdgeGraph`，等待两个合法 A 均已存在后加入原始 AA 摘要因子。每边一个显式因子，solver 返回的新索引绑定后才提交账本。原始 AA 在此模式仅审计为 `AA_STATIC_CHANNEL_ONLY`，防止两通道计权；TA 路径保留。旧地图无精确账本时拒绝静态通道启动，原始 AA 标记 `MAP_AA_OVERLAP_UNKNOWN`，不影响合法 TA。

`liuo_joint_map_static_v2` 暂保留旧 A/L 联合状态，额外强制精确账本并检查叶端点在地图中。后验和账本使用同一 JSON 临时文件及 rename 导出。它只解决静态 AA 信息生命周期，不代表曲线初始化或 A-only 地图已实现。车辆图重置时保留物理记录，只有原先加载地图的叶仍标为 prior 吸收；本次在线新增叶回到有界待接入集合，避免把已丢弃图的信息记作已融合。

`tools/static_replay.py` 当前只支持审计过的 S 模拟器来源：一个原始 source sequence 对应一次独立物理交换。命名空间绑定实际冻结 MCAP SHA256，忽略交付 driver session；同包重复回放不会创造新的物理身份。输入只来自原包实际送达的 AA，保留采集时刻和物理测量方。新的独立噪声包须具有新的原始内容身份。该映射不适用于真实驱动，也不自动推广至 L；当前只是同时间交付派生，缓存发现/补发和 STATIC-PAIR 仍需另行实现。

新增路径的构建与模块检查不能替代实际生产回放证据；生产闭环验证仍在进行。

## 预声明检查

- 同块及反向交付 1000 次：count、weight、mean、scatter 不变，重复更新集合为空，整数身份要求精确相等。
- 高斯显式图与摘要：已有独立因子图对照使用 cost 绝对差 ≤1e-8、增广信息矩阵相对 Frobenius 差 <1e-12；包含梯度及 scatter，不只比较均值。
- 真实 GTSAM 缺端点更新失败：账本 count 保持零；新求解器上成功重试后恰为一；旧事务不可再次提交。
- 容量、身份冲突、部署变化：拒绝后原账本保持不变。
- 账本序列化恢复：旧叶不重新显式计权；两次恢复之后仍可去重旧叶；负数、溢出、非整数端点及重复叶拒绝。

这些是模块测试标准，不替代旧 AA 超 lag、未知端点延迟入图、实际回调、检查点恢复、60 s 生产负载及 S/L 完整实验。后续结果逐项记录在 `docs/curved_tunnel_static_aa_results.md`。

## L 已交付原始消息派生与联合候选

`road_sim_global_exchange_v1` 仅适用于冻结 road_scene 模型：物理请求排序后、任何报告交付之前分配全局 source_frame_seq，独立高斯噪声在该物理样本处生成。派生器只消费传感器包中已交付的 AA，不读 physical_uwb、基站坐标或真值；保留原采集时刻。物理ID由冻结生成来源SHA256命名空间、全局物理序号和规范化无向端点构成，不含driver或报告方向。leaf.physical_source在此合成模型中声明为规范化第一端点，不冒充接收报告者；原报告身份仍在原batch中。每次软件发布只是交付，不能创造物理样本。场景以外的采集/重录血缘不能自动采用此规则，须保留原物理来源命名空间。

`StaticEdgeGraph::candidate_summaries` 只读未吸收、未入主图的唯一pending leaves，且仅返回“一个未知候选端点＋一个已经存在的A”边。既有A仍是候选联合图中的随机变量，保留其原图相关性；没有把地图点估计当精确值。重复查询不commit、不消耗、不清空，未知对未知不给候选凭空造点；旧已吸收块不会重新加入候选似然。

候选通过既有几何/分支/公共车辆参考检查后，在同一次主图update中添加A、有效原始TA、局部观测以及静态模块当前ready边；原始物理块由静态模块stage/commit唯一持有，候选的AA摘要/协方差不作为第二份观测移交。失败abort保留账本，主图异常仍停止并保留故障，不假称原ISAM2自动回滚。随后的静态更新不会重复增权。测试包括1000次重复交付/候选读取后仍只有两个物理叶、一个累计因子。

## 延迟加入地图 prior 的账本准备（基础模块）

`with_map_prior` 构造独立的待提交owner，不改变当前图或当前账本。它保留本轮已融合的新物理样本和显式因子索引，把尚待定的旧物理块归入即将加入的地图prior；相同ID内容冲突拒绝。若旧图prior包含当前图已经融合的相同块，直接拒绝重叠，不能删除显式因子就假称从旧稠密信息撤销。容量包含旧图已吸收、本轮已融合和待定的总集合。

生产调用必须先准备，再成功加入对应联合地图prior，最后swap owner；图更新失败则丢弃准备对象。该模块本身不会加载prior，也不能提前声明旧地图信息已在当前图。缺失checkpoint拒绝；AA_DISABLED旧图只能以有明确来源的空账本处理，不为无账本v1猜造物理身份。重复旧/新交付不新加权，新独立样本仅更新本轮显式累计因子，旧块仍只在地图prior中。生产协调器与时钟重置后的重新接入仍未完成。
